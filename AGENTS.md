# Инструкции для Codex и других агентов, читающих AGENTS.md

Над репозиторием одновременно работают 5 человек, у каждого свой ИИ-агент. **Правила командной работы — в `CLAUDE.md`. Они обязательны и для тебя**: прочитай его целиком перед любым действием. Общая память команды — этот репозиторий и `TASKS.md`.

## Скиллы команды
Скиллы лежат в `.agents/skills/<имя>/SKILL.md` (копия `.claude/skills/` для Codex, синхронизируется скриптом `scripts/sync-agents-skills.sh`). Когда человек пишет команду из таблицы (с `/` или `$` в начале или просто словами), **открой соответствующий SKILL.md и выполняй его по шагам**.

| Команда | Когда | Скилл |
|---|---|---|
| `/ideate <кейс>` | объявили кейс, нужны идеи | `.agents/skills/ideate/SKILL.md` |
| `/kickoff <кейс>` | ведущий: каркас, контракт, задачи | `.agents/skills/kickoff/SKILL.md` |
| `/next <Имя>` | взять задачу, сделать, закрыть, взять следующую | `.agents/skills/next/SKILL.md` |
| `/peer-review <имя>` | ревью коммитов коллеги | `.agents/skills/peer-review/SKILL.md` |
| `/polish <маршрут>` | довести UI до вау | `.agents/skills/polish/SKILL.md` |
| `/ai-feature <что>` | AI-функция с демо-режимом | `.agents/skills/ai-feature/SKILL.md` |
| `/demo-data <что>` | правдоподобные демо-данные | `.agents/skills/demo-data/SKILL.md` |
| `/smoke` | проверить, что main работает целиком | `.agents/skills/smoke/SKILL.md` |
| `/deploy` | публичная ссылка и QR | `.agents/skills/deploy/SKILL.md` |
| `/pitch` | слайды, текст, вопросы жюри | `.agents/skills/pitch/SKILL.md` |
| `/freeze <мин>` | ведущий: финальные 30 минут | `.agents/skills/freeze/SKILL.md` |

Если в скилле упоминается инструмент Claude Code (AskUserQuestion, субагенты, Read картинки), используй свой аналог: спроси текстом, работай последовательно, открой картинку доступным тебе способом.

Имя в TASKS.md: `<Имя>-Codex` (например `bash scripts/tasks.sh claim T3 Маша-Codex`), чтобы команда видела, что задачу ведёт Codex. Если параллельно в этой же папке работает Claude Code, предложи человеку отдельный клон репозитория для Codex.

## Самое важное (кратко из CLAUDE.md)
- Задачи захватывай и закрывай **только** через `bash scripts/tasks.sh claim T3 <Имя>` / `bash scripts/tasks.sh done T3 <Имя> "заметка"`. Скрипт сам делает pull, проверку, коммит, push и повтор при гонке.
- Трогай только файлы из колонки «Где» своей задачи.
- Перед каждым пушем: `git pull --rebase` → проверка (раздел «Проект» в CLAUDE.md) → `git push`. Никаких `--force` и `reset --hard`.
- Конфликт — сохрани изменения обеих сторон. Не понимаешь чужой код — остановись и спроси человека.

## Лучшее применение Codex в этой команде
Ты — другая модель, у тебя другие слепые зоны. Самая ценная роль:
1. **Независимое ревью**: каждые ~40 минут `/peer-review all` по чек-листу скилла.
2. **Охота на баги** в main перед деплоем и заморозкой: `/smoke`.
3. **Исследование для питча**: аналоги, цифры рынка, ответы на вопросы жюри (`/pitch`, раздел 5).
Обычные задачи через `/next` тоже бери, когда нет работы из списка выше.
