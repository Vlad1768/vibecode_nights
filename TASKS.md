**Назначение ответственного фиксируется в «Заметках».** Статус `свободна` у назначенной задачи означает, что ответственный ещё не сделал захват своим агентом; это не приглашение другому участнику занять её. После выполнения зависимостей ответственный меняет статус на `в работе: <Имя>-<фактический ИИ>`, делает отдельный коммит и пуш по `CLAUDE.md`. Неподтверждённый старт работы за коллег не отмечаем.

Сначала Влад берёт T25, Ника — T29. После T25 сайт и бот можно делать параллельно на согласованных моках; AI-ядро — после T22 и T29. Готовность клиента Gemini проверяется по текущему статусу T22. Затем Иван запускает общий API и бота, Влад подключает сайт и проверяет весь путь.

T4–T18 описывают прежний шаблон генератора коммерческих предложений и **не входят в текущий план кейса**. Их исторические строки сохранены. R1–R5 и заглушки T1/T2 не распределяются. При слиянии PR #2 Владу нужно устранить повтор номера T22: в `main` он уже занят Gemini; новую запись кейса пронумеровать по актуальному `main`.

Сайт: `fightinvestor.ru`. Сервер Ивана и имена настроек GitHub Actions — в [docs/BOT_SERVER.md](docs/BOT_SERVER.md). T22 завершила клиент Gemini, но живая генерация получила 429 по квоте: перед живым демо T28/T30 нужно проверить доступную квоту и серверный ключ по `docs/GEMINI.md` вместе с Германом.
