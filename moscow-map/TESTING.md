# Проверка версии

Проверено 4 ноября 2026 года в браузере среды разработки на Windows по локальному HTTP:

- Внешняя карта OpenStreetMap действительно отображается; видны метка, управление масштабом и атрибуция.
- Масштабирование меняет масштаб с 10 до 11; перемещение клавишей меняет центр карты.
- Поиск `воробьевы` находит одну запись «Воробьёвы горы»; её выбор обновляет карточку и координаты метки.
- Неизвестное название даёт 0 мест; сброс возвращает 12. Категория «Культура» показывает 4 места.
- «Вся Москва» убирает выбранную метку и показывает общий обзор города.
- Полный экран открывается и закрывается.
- При узком окне ширина содержимого совпадает с шириной страницы, горизонтальной прокрутки нет; карта размещается над каталогом.
- Постоянная ссылка «Открыть карту отдельно» доступна вне карточки выбранного места.
- Ошибок JavaScript в консоли не обнаружено. Встроенный скрипт также прошёл синтаксическую проверку Node.js.

Прямое открытие `file://` браузерный инструмент запретил своей политикой URL; запуск двойным щелчком на Windows и Mac в этой среде не проверен. В файле нет локальных импортов, загрузок соседних файлов или обязательного сервера. Проверку на реальных компьютерах выполните по списку в README.

Отключение сети и отказы внешнего сервиса отдельно не имитировались. Событие загрузки iframe не доказывает успешную отрисовку карты; поэтому внешняя ссылка остаётся доступной всегда.
