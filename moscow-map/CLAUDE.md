# Работа Claude с картой Москвы

Перед редактированием целиком прочитайте `AGENTS.md` в этой папке, а также `../CLAUDE.md`, `../TASKS.md` и `../docs/CONTRACT.md`. Устройство приложения, запуск и проверка описаны в `README.md`.

Герман явно запросил отдельную ветку для тестового приложения: используйте `feat/moscow-map` как базу, свою ветку — для доработки, pull request направляйте в `feat/moscow-map`. Это согласованное исключение из описанной в корневом README работы в `main`; оно записано в журнале решений `../TASKS.md`. Остальные командные правила, включая отдельный коммит и пуш захвата задачи до кода, действуют.

Сохраняйте запуск приложения одним `index.html` по двойному щелчку на Windows и Mac, без сборки и установки зависимостей. Не убирайте атрибуцию OpenStreetMap. Меняйте только файлы своей задачи и перед передачей выполняйте проверки из местного README.
