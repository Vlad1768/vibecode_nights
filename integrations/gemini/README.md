# Серверный клиент Gemini

Модель по выбору Германа: **`gemini-4-argon`**. Реальные настройки берутся из `GEMINI_API_KEY` и `GEMINI_MODEL` на сервере.

- `client.mjs` — REST-клиент без сторонних зависимостей для Node.js 24.
- `client.d.mts` — типы для серверного TypeScript-кода.
- `client.test.mjs` — автономные тесты с подменой сети и синтетическими ключами.
- `smoke.mjs` — проверка доступа к модели; генерация запускается отдельным флагом.

Запуск, пример вызова, обработка ошибок и состояние живой проверки: [docs/GEMINI.md](../../docs/GEMINI.md).
