# /deploy — ссылка, которая работает на сцене

Режим: «текст, который человек написал после команды» (по умолчанию `vercel`). **Первый деплой — сразу после каркаса.** Дальше каждый пуш в main выкатывается сам, и к финалу деплой уже отлажен.

## A. Vercel из GitHub (основной, ~5 минут, делает человек в браузере)
Веди человека по шагам:
1. vercel.com → войти через GitHub → **Add New… → Project** → Import репозитория. Если репозиторий не виден, нажми «Adjust GitHub App Permissions» и дай доступ.
2. **Root Directory**: `web`. Framework определится сам (Next.js).
3. **Environment Variables**: `ANTHROPIC_API_KEY` (если есть) и `DEMO_MODE=0`. Без ключа ставь `DEMO_MODE=1`: продукт работает на фикстурах.
4. **Deploy.** Ссылка вида `https://<проект>.vercel.app`. Каждый пуш в `main` деплоится автоматически, ветки получают preview-ссылки.
5. Поменял env — сделай **Redeploy** (Deployments → … → Redeploy): переменные применяются только к новым сборкам.

## B. Vercel CLI (если нельзя через GitHub)
```bash
cd web
npx vercel@latest login          # один раз, лучше заранее
npx vercel@latest --prod --yes   # первый раз создаст проект
npx vercel@latest env add ANTHROPIC_API_KEY production
npx vercel@latest --prod --yes   # передеплой с env
```

## C. Туннель с ноутбука (план Б на случай, если облако подвело)
```bash
cd web && npm run build && npm run start          # в фоне, порт 3000
npx -y cloudflared tunnel --url http://localhost:3000
```
Ссылка `https://….trycloudflare.com` появится в выводе, аккаунт не нужен. Первый запуск скачивает бинарник, поэтому прогони его заранее, ещё до хакатона. Ноутбук не закрывать, сон отключить.

## Проверка после деплоя (обязательно)
```bash
node scripts/shot.mjs --base https://<проект>.vercel.app / /<главный-маршрут>
```
Посмотри скриншоты. Пройди AI-шаг на живой ссылке: если ключ не подхватился, должен сработать демо-режим, а не ошибка.

## QR для последнего слайда
```bash
npx -y qrcode -w 800 -o pitch/qr.png "https://<проект>.vercel.app"
```

## Частые причины «локально работает, на Vercel — нет»
- **Регистр в импортах**: macOS и Windows не различают `Card.tsx` и `card.tsx`, а Linux на Vercel различает. Сверь имена файлов и импортов.
- **Нет env-переменной** или забыли сделать Redeploy после её добавления.
- **Неверный Root Directory** (должен быть `web`).
- **Зависимость установлена глобально**, а не в `web/package.json`.
- Логи: Vercel → Deployments → упавший деплой → Build Logs. Скопируй ошибку и чини локально через `npm run build`.
