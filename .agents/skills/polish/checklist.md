# Чек-лист разбора экрана

Иди сверху вниз и выписывай найденное. Исправляй в порядке «насколько это заметно жюри».

## Признаки «сгенерил нейросетью» — убрать первыми
- [ ] Фиолетово-синий градиент на весь hero, «стеклянные» карточки без причины.
- [ ] Эмодзи вместо иконок (🚀✨📊). Нужны иконки lucide-react одного размера и толщины.
- [ ] «Добро пожаловать в <Название>!» или «Революционная платформа на базе AI». Нужна конкретная ценность с цифрой.
- [ ] Сетка из 3–6 одинаковых карточек «фич» с иконкой в кружке.
- [ ] Всё отцентрировано, всё одного размера, нет главного элемента.
- [ ] Лорем, «Test 1», «John Doe», `user@example.com`, $ вместо ₽, английские даты.
- [ ] Серые прямоугольники-заглушки вместо картинок и графиков.
- [ ] Шрифт по умолчанию, русские буквы другим шрифтом (нет `cyrillic` в subsets).

## Обязательное
- [ ] **Иерархия**: за 3 секунды понятно, что это за экран и что тут главное действие (одна primary-кнопка).
- [ ] **Сетка и ритм**: одинаковые отступы по шкале 4/8, контент ограничен по ширине, выровнен по левому краю.
- [ ] **Типографика**: 3–4 размера на экране, заголовки 600–800, вторичный текст приглушён, строки ≤ 75 символов.
- [ ] **Цвет**: акцент только на главном. Статусы — цветные бейджи (успех, ожидание, ошибка), контраст текста достаточный.
- [ ] **Состояния**: loading (скелетон по форме контента), empty (иллюстрация или иконка, одна фраза и действие), error (по-человечески и кнопка «Повторить»), success (тост).
- [ ] **Интерактив**: hover, active и focus-visible у всего кликабельного. У кнопок курсор-указатель и видимое состояние нажатия. Во время запроса кнопка блокируется и показывает спиннер.
- [ ] **Формы**: подписи над полями, плейсхолдер-пример («Например, Иван Петров»), ошибка под полем, Enter отправляет.
- [ ] **Данные**: числа через `Intl.NumberFormat("ru-RU")`, валюта `₽` после числа через неразрывный пробел, даты относительные («сегодня, 14:20», «вчера»), длинные строки обрезаются с `…`.
- [ ] **Мобильная версия (390 px)**: нет горизонтальной прокрутки (shot.mjs проверяет это сам), кнопки ≥ 44 px, таблицы превращаются в карточки или скроллятся внутри контейнера.
- [ ] **Тексты интерфейса**: глаголы в кнопках («Создать отчёт», а не «Отправить»), без канцелярита, единый тон из DESIGN.md.
- [ ] **Консоль чистая**: shot.mjs не показывает ошибок, нет предупреждений про `key` и гидрацию.

## Что даёт вау (выбери 1–2 на экран)
- **Результат AI появляется вживую**: стрим текста, этапы («Читаю данные → Считаю → Готово»), подсветка найденного.
- **Цифра эффекта крупно**: «−37% времени», «сэкономлено 12 часов», с анимацией счётчика.
- **До/после**: хаос входных данных слева, структурированный результат справа.
- **Объяснимость**: «почему AI так решил» — 2–3 причины со ссылками на данные.
- **Микро-радость**: плавное появление карточек (`animate-in fade-in slide-in-from-bottom-2`, если подключён tw-animate-css; иначе `transition` + `opacity`), конфетти после ключевого действия (только одно на продукт).
- **Живое превью в hero** вместо абстрактной картинки: настоящий виджет продукта с данными героя демо.
