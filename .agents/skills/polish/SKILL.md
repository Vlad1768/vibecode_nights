# /polish — интерфейс, который выигрывает у шаблонных

Цель: «текст, который человек написал после команды». Это либо маршрут или компонент для полировки, либо `design-system` для старта.

Жюри смотрит продукт 3 минуты. Первые 5 секунд решают, «настоящий» он или «хакатонная поделка». У конкурентов те же модели и те же шаблоны, а выигрывает тот, у кого **узнаваемый стиль, правдоподобный контент и проработанные состояния**.

## Режим `design-system` (на kickoff, ≤5 мин)
1. Выбери направление из [directions.md](directions.md) под аудиторию продукта.
2. Перенеси токены в `web/src/app/globals.css`, а шрифты — в `layout.tsx` через `next/font/google` с `subsets: ["latin", "cyrillic"]`.
3. Запиши `docs/DESIGN.md`: направление, токены, шрифты, радиусы, тени, сетку, фирменную деталь, тон текстов и 5 правил для всех. Это и есть договорённость, по которой 5 агентов делают единый продукт.

## Режим полировки страницы (≤25 мин, 2 круга)
Правь только файлы своей задачи. Если нужно поменять глобальные токены, это задача ведущего.

1. **Снимок**: dev-сервер запущен → `node scripts/shot.mjs /<маршрут>` → посмотри `.shots/<маршрут>-desktop.png` и `-mobile.png`.
2. **Разбор** по [checklist.md](checklist.md): выпиши 5 самых заметных проблем, отсортировав по тому, насколько их видно жюри.
3. **Исправь эти 5** и ничего больше: полировка без фокуса съедает час.
4. **Снимок снова**, сравни. Второй круг — следующие 3–5 проблем. На этом стоп.
5. `npm run build` → коммит → пуш.

## Быстрые приёмы с большим эффектом
- **Иерархия**: на экране одна главная кнопка, один крупный заголовок и вторичный текст приглушённым цветом. Крупнее, жирнее, контрастнее только главное.
- **Ритм**: отступы из шкалы 4/8/12/16/24/32/48/64, контент ограничен по ширине (`max-w-6xl mx-auto px-4 sm:px-6`), одинаковые радиусы.
- **Контент вместо заглушек**: реальные имена, суммы `12 490 ₽` (через `Intl.NumberFormat("ru-RU")`), даты «сегодня, 14:20». Цифры важнее слов.
- **Состояния**: скелетоны при загрузке, дружелюбный пустой экран с действием, понятная ошибка с кнопкой «Повторить», тост после действия.
- **Движение**: hover и active у всего кликабельного, `transition` 150–200 мс, плавное появление результата AI (стрим или fade-in). Без каруселей и параллакса.
- **Фирменная деталь**: одна запоминающаяся вещь — акцентный цвет в ключевых цифрах, необычный бейдж статуса, иллюстрация из геометрии, крупная цифра эффекта.
- **Hero главного экрана**: что это, для кого, главный результат с цифрой, кнопка входа в демо и превью продукта (скриншот или живой виджет), а не абстрактный градиент.
