# /freeze — довести до сдачи без паники

До конца: «текст, который человек написал после команды» минут. С этого момента **новых фич нет**. Есть только то, что делает демо надёжнее и красивее.

## 1. Снимок ситуации (3 мин)
```bash
bash scripts/tasks.sh status
git log --oneline -15
```
Сверь с демо-сценарием из `docs/PRODUCT.md` и составь таблицу «шаг сценария → работает / сломан / не сделан».

## 2. Решения (2 мин, озвучь человеку для команды)
- Что **доделываем** (≤10 минут работы и находится на пути демо).
- Что **прячем**: недоделанные экраны убираем из навигации или ставим за флаг. Сломанное жюри видеть не должно.
- Что **режем** из демо-сценария, если шаг не успеваем.
Сообщение команде (выведи текстом):
```
ЗАМОРОЗКА. Новых задач не берём. За 10 минут довести текущую до рабочего или откатить свои незапушенные правки.
Дальше — только фиксы из списка ниже. Каждый пуш: git pull --rebase → npm run build → git push.
<список фиксов: кто — что>
```
В «Журнал решений» в TASKS.md добавь строку «Заморозка в <время>: прячем …, режем …».

## 3. Фиксы (до T-15 мин)
Запусти `/smoke`. Чини в порядке «видно в демо → видно на главной → остальное». Каждая правка — маленький коммит с проверкой сборки.

## 4. Финальный деплой (T-15 мин)
`/deploy`: убедись, что последний коммит main выкатился. Затем `node scripts/shot.mjs --base <прод-URL> <маршруты демо>`, посмотри скриншоты и пройди AI-шаг на проде. Если что-то не так, проверь, что `DEMO_MODE=1` спасает.

## 5. Чек-лист готовности
- [ ] `npm run build` зелёный, в консоли на пути демо нет ошибок.
- [ ] Прод-ссылка открывается с телефона по QR, мобильная версия не разваливается.
- [ ] Данные в демо-состоянии: герой на месте, никаких «test» и лишних записей от отладки.
- [ ] AI отвечает на проде, а без ключа — фикстурой.
- [ ] `pitch/index.html` с реальными скриншотами и QR, `pitch/deck.pdf` как запасной вариант, `pitch/SCRIPT.md` с путём кликов.
- [ ] Запись экрана всего сценария сделана и лежит на ноутбуке спикера.
- [ ] В начале корневого README.md (если жюри смотрит репозиторий) есть блок о продукте: одна фраза, ссылка, скриншот, `cd web && npm install && npm run dev`. Правила команды ниже не трогаем.
- [ ] В репозитории нет секретов: `git grep -nE "sk-ant-[A-Za-z0-9_-]{20,}"` ничего не находит, `.env.local` не в git.
- [ ] По желанию — метка версии: `git tag -a demo -m "версия для жюри" && git push origin demo`.

## 6. Репетиция (последние 10 мин)
Два прогона с таймером: спикер ведёт, второй человек кликает демо или страхует. После первого прогона режь текст, а не демо. Во время выступления в main никто ничего не пушит: прод должен оставаться стабильным.
