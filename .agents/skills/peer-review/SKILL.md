# /peer-review — быстрое ревью коллеги (≤10 минут)

Аргументы: «текст, который человек написал после команды». Имя коллеги, или `all` — все, кроме меня. Окно — 60 минут, если не сказано иное.

## 1. Собрать изменения
```bash
git pull --rebase
git log --since="60 minutes ago" --format="%h %an | %s" --no-merges
```
Имя в git может отличаться от имени в TASKS.md, поэтому сверься со строками `готово: <Имя>` в TASKS.md. Отбери коммиты коллеги и посмотри их: `git show --stat <sha>`, затем `git show <sha>` для значимых. Сначала смотри то, что входит в демо-сценарий.

## 2. Проверить (по убыванию важности)
1. **Сборка и запуск**: `cd web && npm run build`. Красная сборка в main — проблема №1 для всей команды.
2. **Секреты**: в коммитах нет `.env*`, ключей `sk-…`, токенов. Если нашёл — сразу скажи человеку: ключ нужно перевыпустить, а файл удалить из репозитория отдельным коммитом.
3. **Контракт**: имена полей, пути роутов и формы ответов совпадают с `docs/CONTRACT.md` и `types.ts`. Нет второго определения тех же типов.
4. **Явные баги**: обращение к `undefined`, пропущенный `await`, нет `key` в списках, бесконечный `useEffect`, хуки без `"use client"`, захардкоженный `localhost` в клиентском коде, ошибки гидрации (`Date.now()`, `Math.random()` в рендере).
5. **Зоны**: правки вне колонки «Где» своей задачи, особенно в общих файлах (`layout.tsx`, `globals.css`, `types.ts`, `components/ui/`).
6. **Демо-качество**: лорем и «Test 1», английские плейсхолдеры в русском UI, нет состояний loading/empty/error, вёрстка ломается на мобильном, мусорные `console.log`. Если страница затронута, сделай скриншот: `node scripts/shot.mjs /<маршрут>`.

## 3. Действовать
- **Мелочь, очевидная, ≤10 строк** — исправь сам коммитом `review(<папка>): <что>`, затем `git pull --rebase && git push`.
- **Крупное или спорное** — новая задача: `bash scripts/tasks.sh add "Фикс: <что> (<файл>, <sha>)" "<файл>" "—"`.
- Чужую логику не переписывай и чужие файлы не удаляй.

## 4. Отчёт человеку (≤10 строк)
```
Ревью <имя>, <N> коммитов: сборка ✓/✗
Исправил: … (коммиты)
Завёл задачи: T… — …
Обратить внимание: …
```

Совет: если у кого-то в команде есть Codex, пусть он делает такое же ревью параллельно. У другой модели другие слепые зоны (инструкции для него — в `AGENTS.md`).
