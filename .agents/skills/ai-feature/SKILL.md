# /ai-feature — AI-функция, которая не подведёт на сцене

Задача: «текст, который человек написал после команды».

## Главное правило
**Демо не должно зависеть от сети, ключа и настроения модели.** Каждый AI-вызов имеет заготовленный ответ (fallback). Он красиво показывается, если ключа нет, включён `DEMO_MODE=1`, API упал, истёк таймаут или модель отказала. Всё это уже заложено в шаблонах ниже: они проверены сборкой, линтом и запуском в обоих режимах.

## Готовые шаблоны (копируй, не пиши с нуля)
| Файл-шаблон | Куда | Зачем |
|---|---|---|
| `.claude/skills/ai-feature/templates/ai.ts` | `web/src/lib/ai.ts` | `askText`, `askJson` (zod), `streamText`, демо-режим, серверный фолбэк Anthropic |
| `.claude/skills/ai-feature/templates/route-json.ts` | `web/src/app/api/<имя>/route.ts` | структурированный ответ для карточек, оценок, списков |
| `.claude/skills/ai-feature/templates/route-chat.ts` | `web/src/app/api/chat/route.ts` | стриминговый чат или длинный текст |
| `.claude/skills/ai-feature/templates/use-ai-stream.ts` | `web/src/lib/use-ai-stream.ts` | клиентский хук для стрима |

Если `web/src/lib/ai.ts` уже есть, не перезаписывай его, а используй. Зависимости: `npm i @anthropic-ai/sdk zod` (если ещё нет, запиши в «Журнал решений»).

## Шаги
1. **Определи форму результата.** Для UI почти всегда лучше JSON: карточки, оценка, список действий, таблица — `askJson` + zod-схема. Свободный текст бери для чата и длинных ответов: `streamText`. Схема = то, что рисует UI. Если её нет в `docs/CONTRACT.md`, скажи об этом ведущему.
2. **Напиши fallback первым.** Это идеальный ответ для главного шага демо-сценария (`docs/PRODUCT.md`) на данных «героя» из моков. Положи его в `web/src/data/ai-fixtures.ts`. Fallback должен выглядеть как лучший возможный ответ модели: конкретный, с цифрами, на русском.
3. **Промпт.** Системный промпт: роль, задача, формат, язык, длина. Данные передавай в виде JSON-контекста из наших моков или ввода пользователя. Пример хорошего ответа в промпте заметно поднимает качество. Попроси конкретику и цифры из данных, запрети выдумывать то, чего в данных нет.
4. **Роут** по шаблону. Ключ читается только на сервере: никаких `NEXT_PUBLIC_` для ключей и никаких вызовов API из браузера.
5. **UI.**
   - Кнопка действия с состоянием загрузки и этапами («Анализирую данные…»). Если ответ дольше 2 секунд, покажи прогресс или стрим.
   - Результат появляется плавно, а не прыжком.
   - Если пришёл флаг `demo: true`, ничего пользователю не говори: это нормальный ответ. Пометку можно вывести только в `console.info`.
   - Ошибка сети на клиенте → понятное сообщение и кнопка «Повторить».
6. **Проверь оба режима.**
   ```bash
   # без ключа (демо)
   curl -s -X POST localhost:3000/api/<имя> -H 'content-type: application/json' -d '{...}'
   # с ключом: ANTHROPIC_API_KEY в web/.env.local, перезапусти dev-сервер, повтори запрос
   ```
   Если ключа ни у кого нет, работай в демо-режиме. Скажи ведущему, что AI пока на фикстурах.

## Модель и скорость
- По умолчанию `claude-opus-5-5` с `effort: "low"`: быстро и умно. Значения меняются через env: `AI_MODEL`, `AI_EFFORT=medium`, если не хватает глубины.
- Если ответ всё равно медленный для интерфейса, предложи человеку `AI_MODEL=claude-sonnet-5-5` или `claude-haiku-5-5`. Решение за командой, сам не переключай.
- В `ai.ts` включён серверный фолбэк Anthropic (`fallbacks: "default"`): если модель отклонит запрос, API сам повторит его на рекомендованной модели. Это не заменяет наш fallback на фикстуру.
- Thinking на Opus 5.5 всегда адаптивный. Параметр `thinking` не передавай, глубину регулируй через `effort`.

## Ключ API
Подписка Claude Max **не даёт** API-ключ для кода продукта. Нужен ключ из console.anthropic.com с небольшим балансом (на хакатон хватит $5–10) или ключ, выданный организаторами. Ключ хранится в `web/.env.local` и в env Vercel. **Не коммить.** Если ключ попал в git, его надо сразу перевыпустить.

## Чего не делать
- Не вызывай LLM на каждый рендер или ввод символа: только по действию пользователя или один раз с кэшем.
- Не обещай в UI того, что модель не делает. Не показывай пользователю сырой JSON и тексты ошибок API.
- Не строй агентов с инструментами, если хватает одного вызова с хорошим промптом и данными в контексте.
