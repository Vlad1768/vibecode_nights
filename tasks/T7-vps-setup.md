# T7. Подготовить Ubuntu VPS, SSH и Docker

Зависимость: T5. Статус и владелец: [TASKS.md](../TASKS.md).

**Результат:** подготовленное серверное окружение и `docs/server-setup.md` с проверками, владельцем и схемой доступа без секретов.

## До начала

Владелец предоставляет реальный VPS, IP, начального пользователя, путь SSH-ключа и разрешения на изменения. Ubuntu Server 24.04 — исходное условие учебного маршрута. Размер из презентации является примером; бюджет, регион и ресурсы подтверждает владелец. Покупку VPS автоматически не выполнять.

## Работа

- Проверить существующие проекты, службы, порты и установленные контейнерные инструменты; сохранить чужую конфигурацию.
- Настроить SSH-ключ и сверить отпечаток сервера с доверенным источником. Существующий приватный ключ не заменять и не пересылать.
- Подготовить пользователя `deploy` с нужными правами. Проверить вход во второй SSH-сессии до закрытия первой.
- Настроить firewall хоста и провайдера, сохранив фактический SSH-порт. Для сайта предусмотреть 80/443; polling-боту входящие прикладные порты не нужны.
- По актуальной официальной инструкции установить Docker Engine и Compose либо проверить имеющуюся установку. Не выполнять рецепт поверх конфликтующей системы вслепую.

## Готово, когда

Вход как `deploy` воспроизведён, Docker запускает проверочный контейнер, Compose показывает версию. Исходящая сеть доступна нужным сервисам выбранного маршрута. Зафиксированы открытые порты, ограничения и восстановление SSH-доступа. При отсутствии доступов задача отмечена блокированной; настройка не считается выполненной по одному документу.

Основание: физические слайды 29–33 (П08–П12), 51 (П30).
