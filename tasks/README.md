# Задачи по практикуму из презентации

План по `AI-development-minimal-with-screencasts.pptx`, 53 слайда, включая заметки докладчика. Обновлён 6 ноября 2026 года по уточнению Германа.

## Что нужно сделать

Пройти учебный путь: подготовить локальный пример, перенести его на отдельный сервер, проверить запуск без ноутбука, HTTPS для сайта, перезапуск, резервную копию и откат. Итог — работающий внешний адрес сайта или реальный ответ бота и понятная инструкция управления.

В практикуме три варианта: **Telegram-бот**, **статический сайт**, **сайт с Node-сервером**. Сначала выбирают нужный вариант. Все три службы одновременно запускать не требуется. Подключение ИИ — дополнительный шаг после эхо-бота. [Подробности вариантов](optional-routes.md).

Это план по материалу презентации, а не подтверждение выполненного деплоя. Реальные VPS, домен, Telegram-токен, API-ключ и разрешения на изменения инфраструктуры предстоит получить для выбранного варианта.

## Как работать

Перед задачей прочитайте корневые `CLAUDE.md`, `TASKS.md` и `docs/CONTRACT.md`. Обновите свою копию, проверьте зависимости, захватите свободную задачу отдельным коммитом и сразу запушьте по правилам команды. Меняйте только файлы своей задачи. В конце укажите фактические проверки, ограничения и следующий шаг.

Если нужны новые файлы или меняется выбранный маршрут, заранее уточните область своей строки в `TASKS.md`. Не публикуйте `.env`, токены и приватные ключи. Покупки, изменение доступа и общие перезагрузки выполняются только в пределах соответствующего поручения владельца.
