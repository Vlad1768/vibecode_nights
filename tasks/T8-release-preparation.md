# T8. Подготовка воспроизводимой публикации

Зависимости: T6, T7. Статус и владелец: [TASKS.md](../TASKS.md).

**Результат:** необходимые файлы в `deploy/` и инструкция `deploy/README.md` для выбранного размещения.

## Работа

- Сохранить `moscow-map/index.html` единственным исходным HTML приложения; не добавлять обязательную сборку, npm или дублирующую редактируемую копию страницы.
- Для выбранной платформы описать публикацию папки `moscow-map/`, ветку и точную версию. Добавить конфигурацию только если она требуется платформе.
- Если выбран VPS: подготовить `deploy/compose.yaml`, `deploy/Caddyfile`, `deploy/.env.example`. Caddy раздаёт HTML и публикует 80/443; Node и бот для этой карты не требуются.
- В варианте VPS предусмотреть автозапуск, ограничение логов и сохранение сертификатов. Пример настроек содержит безопасные значения без секретов.
- Описать запуск, проверку, обновление и откат с корректными путями относительно `deploy/`.

## Готово, когда

Конфигурация проходит доступную проверку для выбранного размещения; инструкция с чистой копии приводит к готовому выпуску без догадок о путях. Для Compose выполнена проверка конфигурации. Прямое открытие HTML остаётся возможным. Реально проведённые проверки и ограничения перечислены.

Публичный выпуск выполняется в T9 после появления нужных доступов и согласования внешних изменений.

Основание: слайды 8, 23, 39 и 43–44.
