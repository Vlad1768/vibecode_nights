# T6. Реализовать и проверить выбранный пример локально

Зависимость: T5. Статус и владелец: [TASKS.md](../TASKS.md).

**Результат:** работающий код только выбранного маршрута и `docs/local-testing.md` с командами, окружением и фактическими результатами.

## Работа

- Бот: подготовить `bot/bot.py`, `bot/requirements.txt` для Python 3.12+, `.env.example` и исключения Git. В личном чате `/start` сообщает ID отправителя; эхо доступно только ID из `ALLOWED_USER_IDS`. Пустой список закрывает эхо всем. Один токен обслуживает один polling-процесс.
- Если после эхо выбран ИИ: один API-запрос на сообщение без повторов; максимум 1000 символов входа и 300 токенов выхода, пауза 10 секунд, тайм-аут 30 секунд. Запрещённые и отклонённые сообщения не вызывают API. Ключ остаётся на серверной стороне; нужен бюджет провайдера.
- Статика: реализовать `site/index.html` и необходимые assets; проверить загрузку страницы. Серверный Node и `/healthz` этому варианту не нужны.
- Node: подготовить `web/server.mjs`, `web/public/index.html`, package-файлы. Проверить production build/start, прослушивание `0.0.0.0:3000`, главную страницу, `/healthz` с `{"ok":true}` и 404.

## Готово, когда

Есть воспроизводимый локальный запуск, обычный и ошибочный сценарии, проверка доступа для бота. Непроведённые проверки названы. Секреты отсутствуют в Git и браузерном коде. Актуальность пакетов, модели и API проверена перед использованием; новые зависимости записаны в журнал решений. Не выбранные варианты не реализуются.

Основание: физические слайды 24–28 (П03–П07), 39–40 (П18–П19).
