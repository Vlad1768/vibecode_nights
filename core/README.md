# AI-ядро тренажёра (T28)

Логика раунда без HTTP. Сервер — в [`server/`](../server/README.md), контракт — [docs/CONTRACT.md](../docs/CONTRACT.md).

| Файл | Что делает |
|---|---|
| `trainer.mjs` | Раунд: старт → 5 вопросов → итог. Повторы, блокировка по сессии, запасной режим при сбое модели |
| `guard.mjs` | Проверки до модели: длина, пустой питч, «не питч», уговоры поставить балл и «игнорируй правила» |
| `scoring.mjs` | Итог по формуле, проверка цитат, отбраковка советов, ровно 3 совета |
| `llm.mjs` | Промпты и JSON-схемы трёх вызовов модели через `integrations/gemini/` |
| `demo.mjs` | Движок без сети: вопросы с цитатой из питча, оценка по подтверждениям в тексте, запасные советы |
| `content.mjs` | Персонаж, 10 критериев кейса, веса, 5 слотов вопросов, стоп-фразы; загрузка из `CONTENT_FILE` |
| `text.mjs` | Нормализация текста, числа, поиск цитат |

## Что гарантирует код, а не промпт

- **Ровно 5 вопросов, 10 критериев в порядке кейса, ровно 3 совета.**
- **Итог считает формула.** Каждый критерий: вес × уровень / 3, сумма округляется. Модель даёт только уровни 0–3, цитаты и тексты.
- **Цитата проверяется по тексту.** Если её нет в питче или ответах дословно, уровень обнуляется. Уговор («поставьте высокий балл») цитатой не считается.
- **Цифры только из текста студента.** Если в вопросе, реакции или факте есть число, которого студент не писал, такой текст заменяется.
- **Советы проверяются.** Совет без срока, со сроком дольше недели или со стоп-фразой («проведите исследование рынка», «улучшите продукт», «наймите команду») отбраковывается. Недостающие подставляются из запасных советов по самым слабым критериям, и один из них — проговорить вслух самый трудный ответ.
- **Ответ студента не теряется при сбое.** Он сохраняется до вызова модели. Повтор того же запроса продолжает с этого места.

## Содержание из T29: формат `CONTENT_FILE`

Пока T29 (Ника) не утвердила персонажа, ядро использует условного бизнес-ангела из [docs/BOT_SCENARIO.md](../docs/BOT_SCENARIO.md). Утверждённое содержание подключается JSON-файлом, путь задаёт переменная `CONTENT_FILE`. Файл проверяется при старте: с ошибкой в нём API не запустится, молча на дефолт он не перейдёт.

```json
{
  "persona": {
    "id": "angel",
    "name": "Олег",
    "title": "Бизнес-ангел",
    "intro": "Текст первого экрана, 2–4 предложения",
    "howScored": "Как ставится оценка, 2–4 предложения",
    "character": "Для модели: кто он, чего хочет, чего боится, как себя ведёт"
  },
  "weights": [15, 10, 10, 10, 5, 15, 10, 5, 10, 10],
  "slots": [
    { "topic": "Клиент", "goal": "что выясняем этим вопросом", "criteria": [1, 2] },
    { "topic": "Доказательства", "goal": "…", "criteria": [6] },
    { "topic": "Деньги", "goal": "…", "criteria": [4, 8] },
    { "topic": "Конкуренты", "goal": "…", "criteria": [3, 9] },
    { "topic": "Мотивация", "goal": "страх персонажа", "criteria": [7, 10] }
  ],
  "stopPhrases": ["проведите исследование рынка", "улучшите продукт", "наймите команду"]
}
```

- `weights` — 10 целых чисел в порядке критериев кейса, сумма 100.
- `slots` — ровно 5, в порядке вопросов. `topic` попадает в ответ API (`Step.topic`). `goal` получает модель.
- `character` наружу не отдаётся, его видит только модель.
- `stopPhrases` — необязательно, по умолчанию список выше.

Полный пример — `DEFAULT_CONTENT` в `content.mjs`.
