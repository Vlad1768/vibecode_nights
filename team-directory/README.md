Смена аккаунта Ратмира не создаёт нового участника или отдельного владельца задач. Специализации и постоянные зоны ответственности остальных участников пока не назначены этим справочником; текущую работу определяет [TASKS.md](../TASKS.md).

## Правила для любого ИИ-помощника

1. Перед работой прочитайте этот справочник, [AGENTS.md](../AGENTS.md), [CLAUDE.md](../CLAUDE.md) и [TASKS.md](../TASKS.md).
2. Определяйте своего участника по сообщению пользователя или подтверждённому GitHub-логину. Учитывайте перечисленные сокращения и регистр. Если соответствие неизвестно или неоднозначно, уточните у человека; не придумывайте имя по нику, папке или имени компьютера.
3. Различайте человека и инструмент. `Герман-Codex` и `Герман-Claude` — помощники одного человека, а не два участника. Существующая запись `герман-Codex` относится к тому же Герману; не переименовывайте старые записи массово.
4. В новых задачах указывайте `<Имя>-<ИИ>`, например `Ника-Claude` или `Герман-Codex`. Инструмент указывайте фактический. Захватывайте задачу отдельным коммитом и пушем по командным правилам.
5. Влад — владелец репозитория. Имя владельца не означает, что текущий помощник работает от его лица. Не назначайте задачи другим участникам и не меняйте их строки без поручения.
6. При подтверждённом изменении состава обновляйте таблицу и JSON вместе. Изменение справочника само по себе не меняет права доступа на GitHub.

## Сообщение для подключения своего ИИ

```text
Меня зовут <Имя>, мой GitHub — <точный логин>.
Прочитай AGENTS.md, CLAUDE.md, team-directory/README.md,
team-directory/members.json и TASKS.md.
Сопоставь мой аккаунт с именем и соблюдай командные правила.
В задачах используй <Имя>-<фактический ИИ-инструмент>.
```
