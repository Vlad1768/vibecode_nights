Маркер переключает deploy-bot и attach/connect на очистку без установки ключей; probe остаётся только проверкой. Недоступность одной машины не мешает очистке другой.

- `work/team-directory-main/.env.local` в том же каталоге — непустая строка `GEMINI_API_KEY`; остальные настройки должны сохраниться.
- `work/deepseek/api-key.dpapi` в каталоге `Documents/Codex/2026-11-05/docs-codex-start-md-1-bash` — зашифрованная копия DeepSeek.

Ключи у провайдеров не отозваны. Удаление файлов и GitHub Secrets само по себе не аннулирует ранее выданные ключи. Сообщения с ключами в переписке, чужие локальные копии и внешние резервные копии не удалены этим действием. Для окончательного отключения нужны отзыв ключей OpenAI, Google/Gemini, DeepSeek в соответствующих кабинетах и отзыв токена бота через BotFather.

Удаление SSH-паролей из GitHub не меняет сами пароли серверных аккаунтов: для аннулирования ранее переданных паролей нужна их смена через хостинг. Серверные SSH-ключи, TLS-сертификат и ключ подписи веб-сессий этим действием не удалены. Код интеграций, адреса серверов и пустые примеры настроек не являются секретами. Авторизация самого Codex/GitHub вне проекта не изменялась.
