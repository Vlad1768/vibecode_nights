Герман передал настройки 6 ноября 2026 года. Telegram-бот и его запуск закреплены за **Иваном** (`ivanthebrave2008`, агент `Ivan-Claude`): T27 и T30 в [TASKS.md](../TASKS.md). Сайт делает Герман (T26), публикацию и итоговую интеграцию ведёт Влад (T32).

| Назначение | Значение | Настройка GitHub Actions |
|---|---|---|
| Сервер бота | `45.147.28.43` | Variable `BOT_SERVER_HOST` |
| SSH-пользователь | `root` | Variable `BOT_SERVER_USER` |
| SSH-пароль | Сохранён зашифрованным в GitHub | Secret `BOT_SERVER_PASSWORD` |
| Домен сайта | `fightinvestor.ru` | Variable `SITE_DOMAIN` |

Настройки находятся в [Settings → Secrets and variables → Actions](https://github.com/Vlad1768/vibecode_nights/settings/secrets/actions). Значение сохранённого секрета GitHub обратно не показывает: Иван использует его в workflow через `${{ secrets.BOT_SERVER_PASSWORD }}`. Если нужен ручной SSH-вход, пароль передаётся лично вне файлов и комментариев GitHub.

Пример передачи настроек шагу GitHub Actions (это фрагмент конфигурации, а не готовый деплой):

```yaml
env:
  BOT_SERVER_HOST: ${{ vars.BOT_SERVER_HOST }}
  BOT_SERVER_USER: ${{ vars.BOT_SERVER_USER }}
  BOT_SERVER_PASSWORD: ${{ secrets.BOT_SERVER_PASSWORD }}
  SITE_DOMAIN: ${{ vars.SITE_DOMAIN }}
```

Пароль нельзя печатать в логах, добавлять в аргументы команд или сохранять в репозитории. Workflow должен передавать его выбранному SSH-инструменту через безопасный ввод/секретное окружение. Автоматический workflow деплоя ещё не создан.
