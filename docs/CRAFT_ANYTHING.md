# Craft Anything: скилл и инструмент для агентов (T41)

[Craft Anything](https://github.com/storytold/craft-anything) — открытый (MIT или Apache-2.0) движок на Rust: изучает готовые программы, сайты, приложения и игры «снаружи» и с доказательствами, а по запросу собирает похожий проект. Даёт агентам 320 инструментов как MCP-сервер и CLI. Статус у авторов — **early alpha**.

## Что уже лежит в репозитории

| Путь | Для кого |
|---|---|
| `.claude/skills/craft-anything/` | Claude Code: подхватывается сам в любой сессии в папке репо |
| `.agents/skills/craft-anything/` | Codex и другие агенты, читающие `.agents/skills/` |

В каждой папке `SKILL.md` и `references/recovery.md` — дословно из `crates/setup/src/` апстрима (коммит `3c5092a`), и `LICENSE` (MIT). Раскладка та же, что делает их установщик, поэтому `craft-anything-cli setup` увидит скилл как уже установленный.

**Важно:** скилл — это только инструкция агенту. Работает он поверх инструментов `craft-anything`, а их даёт программа `craft-anything-cli`. Без неё агент увидит, что инструментов нет, и предложит `craft-anything-cli doctor`.

## Как поставить программу (каждому у себя)

**Вариант 1 — готовая сборка.** [Последний релиз](https://github.com/storytold/craft-anything/releases/latest): Windows `.msi`, macOS `.dmg` (в нём есть CLI) или `craft-anything-cli-…-macos-universal.zip`, Linux-пакеты. Сверяйте `SHA256SUMS.txt`.

**Вариант 2 — из исходников** (нужен Rust 1.97+, `rustup update`):

```bash
git clone https://github.com/storytold/craft-anything
```

```bash
cd craft-anything && cargo install --path apps/craft-anything-cli
```

**Подключить к своему агенту** (сначала посмотреть план, потом применить):

```bash
craft-anything-cli doctor
```

```bash
craft-anything-cli setup --dry-run
```

```bash
craft-anything-cli setup --yes
```

Для одного агента: `--client codex` и т. п. Setup добавляет только запись `craft-anything` в конфиг агента (для Codex — `~/.codex/config.toml`), делает резервную копию и ничего чужого не трогает. После этого **перезапустите** Claude Code / Codex. Удаление — `craft-anything-cli uninstall`.

## Когда пользоваться в нашем проекте

Скилл сам говорит: если есть исходники — читай исходники. Наш код (`bot/`, `core/`, `server/`, `web/`) смотрим обычными средствами, Craft Anything для него не нужен. Полезен он, когда ответ зависит от **чужого готового продукта**:

- **Разбор аналогов (T37, `docs/research/ANALOGS.md`)**: как устроены существующие тренажёры питчей, ИИ-репетиторы, боты-интервьюеры — экраны, сценарий, что они спрашивают. Режим Clean room (по умолчанию) смотрит только снаружи.
- **Проверка нашего сайта и бота как «чужим взглядом»** перед сдачей (T32): страницы на трёх ширинах, что видит пользователь.

## Границы (обязательно)

- **Не копируем чужие продукты** (предложение Ivan-Claude, решение за ведущим). Кейс просит разобраться в похожих форматах — что взять, а что не сработает; воспроизводить чужой сайт, дизайн, тексты или бренд для этого не нужно и рискованно на защите с открытым репозиторием. Поэтому `rebuild` по чужим продуктам не запускаем.
- **Deep mode** (чтение внутренностей программы) и запуск чужого кода — только с явного согласия своего человека; скилл сам требует `consent_required`.
- **Никаких секретов** (токены, пароли сервера, ключ Gemini) в заметки, находки и handoff Craft Anything.
- Рабочие файлы Craft Anything (`Documents/Craft Anything/…`, `investigation.cany/`) в репозиторий не коммитим; в репо — только выводы в наших документах.
