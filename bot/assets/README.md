# Картинки бота

- `welcome.jpg` (или `.png`) — фото к приветствию `/start`. Положите файл сюда и запустите деплой: бот загрузит его один раз и дальше шлёт по `file_id`.
- Вместо файла можно задать `BOT_WELCOME_PHOTO` (file_id или https-ссылка) в окружении бота.
- Без фото приветствие уходит обычным сообщением с теми же кнопками.
