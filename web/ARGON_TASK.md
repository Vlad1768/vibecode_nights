# Задача Gemini Argon: основной интерфейс сайта «Злой инвестор»

Нужен код сайта, никаких слайдов или презентаций. Подготовь `index.html`, `styles.css`, `app.mjs` без сборки и сторонних зависимостей.

Визуальный стиль, ранее выбранный пользователем: яркий оранжевый #ff5c00, почти чёрный #120c09, светло-серый #f3f4f6, жирные заголовки, чат-пузыри. Дизайн должен быть удобен на телефоне и десктопе. Главный заголовок «Злой инвестор», пояснение «ИИ-тренажёр, после которого вопросы жюри не застанут врасплох».

Сценарий: ввод описания стартапа (20–4000 символов), ровно пять вопросов с ответами (до 2000 символов), результат с десятью критериями и тремя конкретными советами, новый раунд. Сохраняй черновик и состояние в sessionStorage, обрабатывай сбой без потери текста, блокируй повторную отправку во время запроса. Доступные label, focus, aria-live и responsive layout обязательны. Не используй innerHTML для пользовательского текста или ответа модели.

API одного origin:
- GET /api/health -> {ready,model}
- POST /api/session {pitch} -> {sessionId,step:1,totalSteps:5,question:{title,text,hint}}
- POST /api/session/:id/answer {answer,step} -> {step,question} либо {done:true,result:{summary,score,maxScore,criteria:[{name,score,maxScore,comment}],tips:[{title,text}]}}
- Ошибка {error:{code,message}}. QUOTA означает недоступную квоту Gemini: показать честное сообщение, не подставлять демо за живой ответ.
- HttpOnly cookie обрабатывается fetch same-origin. Ключей в браузере нет.

Отдельная кнопка «Посмотреть демо» включает явно обозначенный демонстрационный режим. Модуль ./demo.mjs экспортирует CRITERIA:string[10], EXAMPLE_PITCH:string, QUESTIONS:{title,text,hint}[5], DEMO_RESULT:{summary,score,maxScore,criteria:[{name,score,maxScore,comment}],tips:[{title,text}]}. Это фиксированный пример, не оценка пользовательского ввода. Основной режим — Gemini Argon.

Результат задания: JSON {files:[{name,content}]} с тремя полными файлами. Код должен быть готов к запуску статическим сервером и подключению к указанному API. Не добавляй зависимости, внешние trackers, фиктивные отзывы и выдуманные реальные оценки.
