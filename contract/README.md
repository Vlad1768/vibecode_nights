# Контракт API: примеры и mock-сервер

Сам контракт — [docs/CONTRACT.md](../docs/CONTRACT.md). Здесь то, что помогает работать по нему до готовности API (T28).

| Файл | Что это |
|---|---|
| `mock-server.mjs` | HTTP-сервер контракта на заготовках. Node.js 22, без зависимостей |
| `mock-server.test.mjs` | Проверки мока, включая клиент бота `bot/src/api/http.mjs` |
| `examples/*.json` | Настоящие запросы и ответы мока: `start`, `answer`, `done`, ошибки, `persona`, `health` |

```bash
node contract/mock-server.mjs                     # http://127.0.0.1:8080/api/health
node --test contract/mock-server.test.mjs         # 7 проверок
```

- **Бот:** `TRAINER_API_URL=http://127.0.0.1:8080` — и бот ходит в мок вместо встроенной заглушки.
- **Сайт:** в разработке проксируйте `/api` на `http://127.0.0.1:8080` (в Vite: `server.proxy`). На сервере тот же путь `/api` ведёт Caddy.
- **API T28:** должен проходить те же проверки, поменяв адрес. Формат ответов — как в `examples/`.

Примеры пересоздаются из мока; если меняете мок, обновите и их, иначе они разойдутся с контрактом.
